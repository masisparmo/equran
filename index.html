Selamat Datang!

Fitur Analisis Kata Menggunakan AI memerlukan Gemini API Key jika kata tersebut belum ada di database komunitas kami. Silakan masukkan API Key Anda untuk mulai berkontribusi!

Cara Mendapatkan Gemini API Key (Gratis)

  1. Buka Google AI Studio dan login menggunakan akun Google/Gmail Anda.
  2. Klik tombol "Create API key".
  3. Pilih "Create API key in new project" (atau gunakan project yang ada).
  4. Copy (salin) kode API Key yang muncul.
Tips: Anda dapat memasukkan lebih dari satu API Key sekaligus. Cukup pisahkan dengan koma (contoh: key1, key2, key3) dari akun Gmail yang berbeda-beda agar jika satu terkena limit, sistem otomatis menggunakan key lainnya!

Anda juga bisa memasukkan/mengubah key kapan saja melalui menu Settings () di pojok kanan atas.
